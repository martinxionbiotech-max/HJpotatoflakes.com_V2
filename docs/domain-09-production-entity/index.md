## 3. Key Production Parameters (Hongji Facility)

The following are the actual operating parameters recorded in Hongji's food safety system documents:

| Parameter | Value | Reference |
|-----------|-------|-----------|
| Potato origins | Ulagai, Hailar, Tongyu, Siziwang Banner, Naiman | Traceability records |
| Moisture (finished flakes) | ≤ 9.0% | GB 5009.3 |
| Reducing sugars | ≤ 3.0% | GB 5009.7 |
| Ash (dry basis) | ≤ 4.0% | GB 5009.4 |
| Blue value | ≤ 500 | SB/T 10752 Annex A |
| Metal detection | Fe ≤ 1.5 mm, No-Fe ≤ 2.4 mm, SUS ≤ 3.0 mm (verified every 4 h) | CCP record |
| Magnetic separation | ≥ 8,000 Gauss (replace < 7,000 GS, test every 10 days) | CCP record |
| Traceability record retention | ≥ 3 years | Traceability control |
| Reference standard | SB/T 10752-2012 Potato Flakes | Domestic trade standard |
