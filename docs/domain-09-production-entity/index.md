# Production Entity Archive — Meishile Agricultural Technology

This archive documents the food safety management system of **Inner Mongolia Meishile Agricultural Technology Co., Ltd.** (内蒙古美事乐农业科技有限公司) — the potato flake production entity within the Hongji Agriculture supply chain.

> **Relationship Note:** Hongji Agriculture Co., Ltd. (弘基农业) and Inner Mongolia Meishile Agricultural Technology Co., Ltd. are both first-tier domestic potato processing enterprises operating to the same national standards. This archive preserves Meishile's original quality and food safety system documents as first-hand reference material for B2B customers auditing the production supply chain.

## 3. Key Production Parameters (Meishile Facility)

The following are the actual operating parameters recorded in Meishile's food safety system documents:

| Parameter | Value | Reference |
|-----------|-------|-----------|
| Potato origins | 乌拉盖 (Ulagai), 海拉尔 (Hailar), 通榆 (Tongyu), 四子王旗 (Siziwang Banner), 奈曼 (Naiman) | Traceability records |
| Moisture (finished flakes) | ≤ 9.0% | GB 5009.3 |
| Reducing sugars | ≤ 3.0% | GB 5009.7 |
| Ash (dry basis) | ≤ 4.0% | GB 5009.4 |
| Blue value | ≤ 500 | SB/T 10752 Annex A |
| Metal detection | Fe ≤ 1.5 mm, No-Fe ≤ 2.4 mm, SUS ≤ 3.0 mm (verified every 4 h) | CCP record |
| Magnetic separation | ≥ 8,000 Gauss (replace < 7,000 GS, test every 10 days) | CCP record |
| Traceability record retention | ≥ 3 years | Traceability control |
| Reference standard | SB/T 10752-2012 马铃薯雪花全粉 | Domestic trade standard |
