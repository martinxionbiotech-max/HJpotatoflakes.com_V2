# Quality Control & Testing

Quality assurance is the backbone of Hongji Agriculture's commitment to consistent, high-quality potato ingredients. Our quality control system encompasses physical, chemical, and microbiological testing for every production batch, following standardized methods aligned with AOAC, ISO, and food safety standards. Each test result is documented in a Certificate of Analysis, providing full traceability and transparency for B2B buyers worldwide.

## QC Testing Matrix

| Test Category | Parameter | Method | Frequency | Acceptance Criteria |
|:-------------|:---------|:------|:---------:|:------------------:|
| Physical | Moisture | AOAC 934.01 | Every batch | ≤6.0% |
| Physical | Particle Size | ASTM E11 Sieve | Every batch | 0.25-2.0 mm (flakes), ≤250 μm (powder) |
| Chemical | Starch Content | AOAC 996.11 | Daily composite | 75-82% |
| Chemical | Reducing Sugars | DNS/Fehling's | 2x per shift | ≤1.5% |
| Microbiological | TPC | ISO 4833 | Every batch | <10,000 CFU/g |
| Microbiological | Salmonella | ISO 6579 | Every batch | Negative/25g |
